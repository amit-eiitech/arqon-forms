# Arqon Forms

A lightweight dynamic form builder and submission manager for **Laravel 13** and **Filament 5**.

Package: `eii/arqon-forms`  
Publisher: Eii Tech Solutions

## Included in v1.0.0

- Filament 5 form management resource.
- Reorderable JSON-based field builder.
- Public form pages at `/forms/{slug}`.
- Reusable Blade component: `<x-arqon-form slug="contact-us" />`.
- Livewire-powered rendering and submission.
- Server-side validation derived from the saved field definitions.
- Submission records with a field-definition snapshot.
- Submission list, response detail modal, status management.
- Optional email notifications.
- Basic honeypot and per-IP rate limiting.
- Configurable table names and route prefix.

## Requirements

- PHP 8.3+
- Laravel 13
- Filament 5
- Livewire 4 (installed by Filament 5)

## Installation

```bash
composer require eii/arqon-forms:^1.0
php artisan vendor:publish --tag=arqon-forms-config
php artisan migrate
```

Register the plugin in your Filament panel provider (usually `app/Providers/Filament/AdminPanelProvider.php`):

```php
use Arqon\Forms\Filament\ArqonFormsPlugin;

public function panel(Panel $panel): Panel
{
    return $panel
        // ...your existing panel configuration
        ->plugins([
            ArqonFormsPlugin::make(),
        ]);
}
```

If your panel already has plugins, append `ArqonFormsPlugin::make()` to the existing array rather than replacing them.

## Create and publish a form

1. Open your Filament panel.
2. Go to **Forms → Forms**.
3. Create a form and add fields.
4. Use unique field names containing letters, numbers and underscores, such as `full_name` or `email`.
5. Enable **Published** and save.
6. Visit `/forms/{slug}` or embed it in a Blade view.

## Embed a form

```blade
<x-arqon-form slug="contact-us" />
```

The component renders the same Livewire form used by the public form route. Make sure the host layout includes Livewire's scripts and styles; standard Livewire layouts generated by Laravel/Filament normally do.

## Supported field types

`text`, `textarea`, `email`, `number`, `tel`, `url`, `select`, `radio`, `checkbox`, `date`, `toggle`, `hidden`.

For `select`, `radio` and `checkbox`, add options with a label and a stable value. Example field definition:

```json
{
  "id": "field_01",
  "type": "text",
  "name": "full_name",
  "label": "Full name",
  "placeholder": "Your name",
  "required": true,
  "help_text": "Enter your full name",
  "validation": { "min": 2, "max": 100 }
}
```

## Form settings

- Submit button label.
- Success message.
- Optional redirect URL after a successful submission.
- Optional submission limit and start/end date-time values.
- Optional email notifications with one or more recipients.

Email notifications use the host Laravel application's configured mailer. Configure `.env` mail settings in the host application.

## Configuration

Publish the configuration file:

```bash
php artisan vendor:publish --tag=arqon-forms-config
```

Available settings are documented in `config/arqon-forms.php`:

- Database table names.
- Public route prefix, middleware and route name prefix.
- Per-IP rate limit.
- Whether an HMAC IP hash is stored.
- Filament navigation labels/group.

Set a dedicated secret for IP hashing in production:

```dotenv
ARQON_FORMS_IP_HASH_KEY="a-long-random-secret-value"
```

If omitted, the Laravel application key is used. The raw IP address is not stored.

## Local package development

In the Laravel host application's `composer.json`, add a path repository:

```json
{
  "repositories": [
    { "type": "path", "url": "../arqon-forms", "options": { "symlink": true } }
  ],
  "require": {
    "eii/arqon-forms": "@dev"
  }
}
```

Then run:

```bash
composer update eii/arqon-forms
```

The package is auto-discovered by Laravel. Run migrations in the host app.

## Important v1.0 notes

- Field definitions and historical field snapshots are stored as JSON. This keeps the package straightforward and makes it easy to add field types later.
- File uploads, conditional logic, multi-page forms, respondent accounts, payment collection and advanced analytics are intentionally out of scope for v1.0.
- The public renderer is intentionally unopinionated and uses simple inline styling so it works without requiring Tailwind in the host application. Publish the views with `php artisan vendor:publish --tag=arqon-forms-views` to customize the appearance.
- Review your application's authorization, retention and privacy requirements before collecting personal or sensitive data. This package does not provide a full consent-management or data-retention policy.
